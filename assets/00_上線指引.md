# 上線文件導覽 — {{識別}}

本文件是 release 目錄的入口，只說明後續文件的用途與建議閱讀／執行順序；不記錄執行歷程、審查簽核或實際執行結果。

## 文件用途

| 檔案 | 必要性 | 用途 |
| --- | --- | --- |
| `00_上線指引.md` | 必要 | 本導覽與文件使用順序。 |
| `01_結構SQL.sql` | 必要 | 結構變更的可執行 SQL；由核對過的來源或工具產物提供。 |
| `01_索引調整.sql` | 索引名稱或環境定義不確定時 | 依 metadata 判斷索引名稱／定義的受控調整；只有唯一符合才執行，找不到或多個符合時停止。一般確定索引異動仍在 `01_結構SQL.sql`。 |
| `02_資料SQL.sql` | 有資料異動時 | 資料異動、migration 或正式 repair source 的可執行 SQL；沒有資料異動時不建立。 |
| `03_例外排除.json` | 有受控排除時 | 例外排除的唯一結構化來源；記錄排除單位、理由、相依影響、證據與核准；沒有排除時不建立。 |
| `04_參數異動.md` | 有參數異動時 | 參數／設定檔的變更位置、套用方式與生效檢查；沒有參數異動時不建立。 |
| `05_版更審查報告.md` | 審查階段 | 來源完整性、語意等價性與部署驗證狀態。 |

本文件不放 SQL 命令、執行歷程或審查簽核；來源 revision、工具版本、artifact hash、核准與實際執行證據由 artifact metadata／審查資料保存。
